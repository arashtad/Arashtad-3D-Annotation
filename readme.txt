Bring interactive 3D experiences directly to WordPress.

**Arashtad 3D Annotation** lets you display 3D models, animate them, and create interactive annotations that connect information directly to the model. Build everything from technical documentation and educational models to product showcases, architectural presentations, and interactive WooCommerce experiences.

Powered by **Babylon.js**, Arashtad 3D Annotation combines a high-performance real-time 3D engine with a WordPress-native workflow.

== External services ==

This plugin bundles Babylon.js locally and does not intentionally load Babylon.js or user data from an external service.

The bundled Babylon.js KTX2 decoder contains built-in fallback URLs pointing to the Babylon.js CDN (`cdn.babylonjs.com`) for KTX2 transcoder WebAssembly resources. These resources are only requested by Babylon.js when KTX2 texture transcoding requires them. The plugin does not send user or personal data to this service.

Babylon.js: https://www.babylonjs.com/
Babylon.js source and license: https://github.com/BabylonJS/Babylon.js

== Installation ==

1. Upload the `arashtad-3d-annotation` folder to the `/wp-content/plugins/` directory, or install the plugin directly through the WordPress Plugins screen.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to the Arashtad 3D Annotation settings panel to configure your default options.
4. Create a new annotation scene and upload your first 3D model.
5. Insert the scene into any page or post using the Gutenberg block or shortcode.

== Frequently Asked Questions ==

= Does this plugin require any external services? =

The Community version runs entirely on your own server and does not connect to external services. It does not use telemetry or tracking.

The Pro version connects to the Arashtad API server only for license validation and plugin update requests. These requests transmit only license-related information. No website content, visitor data, or other site data is transmitted.

= Where can I find the source code for the Arashtad 3D Runtime? =

The Arashtad 3D Runtime included with this plugin is distributed under the MIT License. The complete human-readable source code is publicly available on GitHub:

https://github.com/arashtad/Arashtad-3D-Runtime

= What 3D model formats are supported? =

GLB, GLTF, GLTF 1.0, OBJ, STL, PLY, Compressed PLY, SPLAT, SPZ, SOG, and `.babylon`.

= Can I use this with WooCommerce? =

Yes. The Pro version includes WooCommerce integration with per-variation model replacement.

= Is the Free version fully functional? =

Yes. The Free version provides a complete foundation for creating responsive 3D experiences with unlimited annotations and scenes.

= Does it work on mobile? =

Yes. The viewer is fully responsive and supports touch rotation, pan, and zoom.
